How each module works
🎤
STT — Groq Whisper 300-700ms
Converts your voice to text. Records WebM/Opus audio in 100ms chunks, assembles them when you stop, and sends the file to Groq Whisper Large-v3-Turbo (216× real-time). From India, the network round-trip adds ~300–700ms unavoidably. Supports Hindi natively — set STT_LANGUAGE=hi in .env.

Key fix: Browsers write the WebM file header only on the first chunk. A headerless blob causes a 400 error from any STT API. AudioCollector scans each chunk for magic bytes (1A 45 DF A3) and drops pre-header data.

⚡
Intent Classifier <1ms
Catches simple answers before any AI is called. Regex patterns match "haan/yes/ji" → YES, "nahi/no" → NO, "15 April" → DATE, "UPI/GPay" → METHOD, "5000/₹5k" → AMOUNT. Handles 70%+ of turns in a payment call with zero network cost.

Auto-advance nodes: PURPOSE, CALLBACK, CAPTURE_EXEC advance on ANY answer — no branching, so the classifier always handles them instantly.
Hits this session: 0
🔮
Semantic Cache FAISS ~5ms
Stores LLM responses and reuses them for similar future answers. Encodes answers into 384-dim vectors (MiniLM model) stored in FAISS. On lookup, finds nearest vector by cosine similarity. If ≥ 0.85 similarity → cache hit, no LLM needed.

"haan bilkul", "ji haan", "ho gaya payment" all map to the same vector cluster — something a key-value cache would miss.
Hits / Misses: 0 / 0
🧠
LLM — Groq Llama 3.1 ~1300ms
Generates natural Hinglish acknowledgements for free-text answers (REASON, CAPTURE_EXEC). Only called when intent classifier AND cache both miss. Tokens stream live to the UI. Each completed sentence fires TTS immediately — first audio arrives ~300ms earlier than waiting for the full response.
Calls this session: 0
🔊
TTS — gTTS Cached <10ms cached
Converts bot text to MP3 audio. All fixed survey questions are pre-synthesised at startup (warm-up), so they always hit the cache in <10ms. The LLM ack text misses on first call (~800ms), then gets cached. Two separate TTS calls per turn: ack (miss) + question (hit) — combined is faster than one merged call because the merged string never matches the cache.
